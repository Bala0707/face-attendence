Tk SaaS — Prototype

This is a lightweight, modular Tkinter desktop app prototype intended as a local, "SaaS-like" desktop application. It uses only Python's builtin `tkinter` and `sqlite3` to keep the environment unchanged.

Quick start

1. Run the app:

```bash
python -m tk_saas.main
```

2. The app stores data in `tk_saas.db` in the working directory.
